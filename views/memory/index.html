故事：她在聊天之外的生活

这里只有运维信息和她自己的视角（状态卡、她记下的事）。完整转录、设定集和主持人笔记会剧透，不在页面上显示，需要时用“导出故事数据”。

生图：参考图库、审核区与提供商

按机器人管理画风/角色/场景/物件参考图与待审候选；生图提供商档案（含密钥）仅保存在插件配置，不写入记忆数据库。

插件配置

和 AstrBot 自带配置页写的是同一份。保存后下一轮就生效，不用重载。密钥留空表示不改。按机器人的 TTS、门控问题和固定上下文，仍在「设置」页。

TTS、固定上下文与门控问题

TTS 未显式绑定为静音；上下文 0 表示关闭，留空跟随全局。门控问题是非 @ 群消息到来时问判断模型的那句话，须写成“概率越高越该回复”；清空或改回配置里的原文即跟随配置。
