# 影忆 ShadowMemory

> 给 AstrBot 里的角色一套会慢慢长大的记忆，也让她能在你不找她的时候，按现实时间过自己的日子、随手拍照、发说说。

作者：绿荫（LvYin3） · 适用版本：**AstrBot ≥ 4.29.3**

---

## 它能给你的机器人带来什么

- **真的会记人记事，慢慢长出性格**
  不是把全部聊天记录硬塞给模型，而是像人一样在相处里慢慢记下共同经历、关于你的信息、对不同人的印象，以及心里没想明白的小情绪。久不提起的日常会自然变淡，反复聊起的事才会记得更牢，时间一长说话和判断都会渐渐带上自己的偏向。

- **聊天之外，按现实时间过自己的日子（故事模块，可选）**
  写一份简单的世界设定交给她，不找她聊的时候，她也会按现实时间去上课、买菜、忙手头的事，遇到常来往的配角还能各自记住彼此。你再找她时，她知道自己这会儿在哪、在忙什么，也了解这个世界的常识（同时不会剧透她本人不该知道的底层秘密），想到你了还会主动发消息过来。

- **更像真人在聊天，而不只是问答机器**
  在群里会自己判断要不要插话，不再每句都接；回复可以像平时发消息一样分成几句说、发语音，或者干脆已读不回。闲下来还会写私密笔记、记备忘提醒、发 QQ 空间说说。

- **会随手拍照，而且长相画风稳得住（生图模块，可选）**
  聊天或过日常时，她可以顺手拍一张眼前的画面发给你、存进自己的图库，或者配上说说发空间。支持提前上传角色本人和画风参考图，出图前会自动审核一遍，尽量不翻车。

- **自带可视化面板（WebUI）**
  配模型、翻看她记住了什么、觉得性格跑偏了回滚版本、开关故事和查看状态卡、上传管理参考图——绝大部分操作在 AstrBot 插件详情页点点鼠标就能完成，不用手改 JSON。

## 快速上手：3 步完成基础初始化

只需要三步，就能把基础记忆和拟人聊天先跑起来：

1. **安装并启用插件**
   把 `astrbot_plugin_shadow_memory/` 放到 AstrBot 的 `data/plugins/` 目录下，在 AstrBot 插件页启用即可。

2. **把 AstrBot 的对话保留轮数改成 `20`（重要）**
   在 AstrBot 对应的配置文件里，找到「压缩前最多保留对话轮数（`max_turns`）」，**不要用默认的 `-1`**，建议改成 `20` 左右。否则聊天上下文会越滚越大，白白消耗大量 token。

3. **在插件 WebUI 填好模型**
   打开插件详情页 →「记忆总览」→「配置」→「模型」：
   - 填好**判断模型**（负责决定群里要不要插话、此刻该想起哪段记忆、哪些事值得记住）；
   - **写作模型**可以留空，留空会自动跟着这个机器人在 AstrBot 里绑定的默认对话模型走；
   - 点击保存，立刻生效，不用重载插件。

到这里基础记忆就已经开始工作了，正常跟她聊天就行。

## 想玩更多？（按需开启，都在 WebUI 里操作）

- **给她「装上过去」（初始记忆）**
  不想从一张白纸开始聊，可以用仓库里的 [`skills/persona-seed/`](skills/persona-seed/SKILL.md) 让 AI 把你口述的角色性格与往事整理成一份 JSON，再到 WebUI「记忆总览」点导入即可。

- **让她在聊天外过日子（故事模块）**
  先用 [`skills/world-seed/`](skills/world-seed/SKILL.md)（或参考 [`docs/world_seed.example.json`](docs/world_seed.example.json)）写一份她生活的世界；然后去 WebUI「配置 → 故事」打开总开关并保存，切到「故事」页选定机器人、导入世界种子、点「开启」。想马上看看效果，直接点「立即演一场」。

- **让她会随手拍照（生图模块）**
  去 WebUI「生图」页填好生图接口档案，上传几张角色本人和画风参考图，再到「配置 → 生图」打开开关就能用。

## 使用前心里有个数

- **关于预期**：它本质是靠记忆系统与提示词拼出来的陪伴感，不是真的有了意识，模型偶尔记混、忘事或走神都很正常；如果觉得性格被带偏，在 WebUI 里可以随时回滚到以前的人格版本。
- **关于花费**：判断模型、故事日常和生图拍照都会额外消耗 API 额度。建议先按默认跑两天看看账单，随时可以在配置里调低频率，或者关掉用不上的模块。
- **关于隐私**：默认会把近期聊天上下文发给外部判断模型来提高准确度；如果介意，在「配置 → 模型」里关掉完整上下文即可。
- **关于平台功能**：发语音、发 QQ 空间和故事主动找你说话依赖对应的平台适配（例如 `aiocqhttp` / NapCat 反向 WebSocket）；纯聊天记忆本身不挑平台。
