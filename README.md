# 影忆 ShadowMemory

> 用记忆塑造人格，也让角色在聊天之外按现实时间过自己的日子。

作者：绿荫（LvYin3）  
目标版本：**AstrBot ≥ 4.29.3**

##### ⚠️ 使用前务必在 AstrBot 中调整「压缩前最多保留对话轮数」，不要使用默认的 `-1`。建议设为 `20`。

---

## 它是什么

影忆围绕两件事展开：**让角色有「过去」**，以及按需开启后**让她在聊天之外有「当下的日子」**。

在聊天里，插件不是把历史记录原样塞进提示词，而是把对话慢慢整理成结构化的记忆：

- 发生过的事 → 事件；
- 确定下来的信息 → 事实；
- 人和事的联系 → 关系边；
- 没想明白的冲突 → 未消解张力；
- 反复出现的模式 → 人格倾向。

开启故事模块后，角色也不再只活在聊天窗口里：背景模型按现实时间主持她的日常，她自己决定行动，经历过的事同样沉淀进上面这套记忆，并通过状态卡、`act` 意图和主动消息与你的聊天双向接通。所有记忆都会经过召回、常驻背景、夜间巩固、人格蒸馏和遗忘曲线，逐渐影响她怎么说话、怎么判断、什么时候沉默。

## 其他拟人化设计

- **第一人称记忆归属**：召回内容明确是“我的记忆”，不是“对方刚说的”；“我”和“小明”在入库时就区分。
- **选择性接话**：群聊非 @ 消息先由判断模型决定要不要接，而不是每条都回复。
- **分段回复与声音**：`say` 说文字、`speak` 发语音、`silent` 选择沉默。
- **遗忘与余波**：S/R 曲线让记忆自然降温；未消解的张力会留下一点情绪余波。
- **常驻背景**：最近的人、事和重要记忆进入 system prompt，只影响语气，不主动提起。
- **生活痕迹**：私人笔记、备忘提醒、图片库、QQ 空间，让角色不只会聊天。
- **夜间整理**：巩固重复事件、抽取事实、蒸馏人格，把短期经历变成长期倾向。

## 原理边界

**这套原理是理想化的工程近似，不是严格的认知科学模型，也不是在模拟真实意识。**

- 不训练模型权重；“人格”来自 persona、system prompt、记忆注入和蒸馏结果的组合。
- S/R 遗忘曲线、实体聚类、巩固、人格蒸馏都是启发式规则，不是对大脑的精确复刻。
- 故事模块是受控的后台叙事生成与状态同步，不是角色真正在后台自主存活。
- 模型可能忽略、误解或违背记忆；效果取决于模型、数据量、配置和平台。
- 记忆越多不一定越好：会增加 token、延迟和上下文噪音，需要配合召回阈值和遗忘机制。
- 不要把它当成“真正会记住一切的电子生命”；它更像一个会随着相处逐渐有偏向的角色层。

## 功能

- **记忆**：事件、事实、关系边、遗忘曲线、张力、人格三层、常驻背景、夜间巩固、人格蒸馏。
- **故事（可选，默认关闭）**：世界种子、现实时间日常推进、与聊天双向接通（`act` / 未回补回 / 远方动作 / 主动消息）、独立配角（NPC）、故事树长线组织。见下文「故事模块」。
- **交互**：群聊门控、`say / speak / silent` 分段回复、最终文本拦截、TTS、固定上下文、第一人称环境。
- **生活**：私人笔记、备忘提醒、图片库、发图、QQ 空间。
- **运维**：WebUI 记忆总览与分层配置页、导入导出与跨机器人转移（`full` 备份及替换转移一并携带故事世界与配角）、`/memory` 与 `/story` 命令、人格回滚。
- **起稿技能**：`skills/persona-seed/` 与 `skills/world-seed/`，把口述过去和生活世界整理成可导入的种子。

## 快速开始

1. 把整个 `astrbot_plugin_shadow_memory/` 放到 AstrBot 的 `data/plugins/`，在 AstrBot 插件页启用；
2. 在 AstrBot 对应的配置文件里把「压缩前最多保留对话轮数（`max_turns`）」改成 `20`；
3. 打开插件详情页 →「记忆总览」→「配置」，进入「模型」卡片填好判断模型与写作模型并保存（保存立即生效，无需重载插件）。

数据目录：

```text
data/plugin_data/shadow_memory/
  memory.db       SQLite（WAL）
  seed/           persona_seed / world_seed JSON（命令导入时使用）
  exports/        导出与备份
  qzone_media/
    <bot_id>/     按机器人隔离的图片库
```

插件不新增第三方运行依赖：HTTP 用 AstrBot 自带的 `httpx`，存储用标准库 `sqlite3`。

## 最小配置

可以直接在插件 WebUI「配置」页填写，对应到底层配置等价于：

```jsonc
{
  "decision": {
    "provider_id": "你的判断 provider ID",
    "full_context": true,
    "full_context_max_chars": 16000
  },
  "text": {
    "provider_id": ""   // 留空用该机器人在 AstrBot 里的默认对话模型
  }
}
```

- `decision` 用于群聊门控、召回选择、生成后判断和重要记忆判断；可以是 AstrBot 的判断 provider，也可以走插件直连兜底。
- `text` 用于碎片、摘要、事实抽取、巩固和人格蒸馏；留空时跟随会话或机器人绑定的默认模型。
- `full_context=true` 会把完整人格和文本历史发给外部 JEV 服务；不想发送隐私就关闭。
- AstrBot 的 `agent_runner.config.compression.max_turns` 默认可能是 `-1`，务必改成 `20`，否则历史会无限增长。

完整配置见 [docs/CONFIG.md](docs/CONFIG.md)。

## 起稿初始记忆与世界（Skill）

仓库自带两个给外部 AI 助手（Cursor / Claude 等）使用的起稿技能，可以通过对话把口述设定整理成严格校验的 JSON：

- **`skills/persona-seed/`（装上过去）**：把你口述的角色性格、相处往事整理成 `persona_seed/v1`（三层人格、稳定事实、代表情景）。在插件 WebUI 点「导入」上传，或放到 `seed/` 目录后私聊发 `/memory import <文件名>`。
- **`skills/world-seed/`（建立生活世界）**：把你口述的生活地点、日常节奏、世界规矩与开场整理成 `world_seed/v1`（示例见 `docs/world_seed.example.json`），会自动对照已有记忆避免矛盾，不擅自编造人物关系与承诺。在插件 WebUI「故事 → 导入世界种子」直接导入，或放进 `seed/` 目录后发 `/story import <文件名>`。

## 故事模块

你写一份「世界种子」（她生活在哪、周围有谁、日子是什么基调），插件用一个「背景模型」当主持人，按现实时间一场一场推进她在聊天之外的日常：

- **现实时间与双模型分工**：时间与现实同步，QQ 就是她手里的手机；每一场里背景模型只写她看到听到的事并裁定结果，她自己决定怎么想、怎么做；结果有悬念时由程序掷骰，不由模型说了算。
- **状态卡同步处境**：每场收场留下一张状态卡（在哪、在做什么、预计到几点、方不方便看手机），聊天时自动并入环境提示，让她知道自己此刻身在何处。
- **与聊天双向接通**：聊天里答应去做的事可用 `act` 工具交进故事；私聊里她选择沉默会记为未回留待补回；自动识别寄东西、点外卖、转账并在场内落定；场内可向私聊或白名单群发主动消息（回告、补回、自发分享分桶限流）。
- **独立配角（NPC）**：背景模型可提名常驻配角，配角拥有自己的三层人格与独立记忆库，久未出场自动休眠、再次同场按空位唤醒。
- **故事树与长线工具**：按主线、人物线与日常组织长线脉络；主持人可按需查旧场与读写笔记、复用 AstrBot 已启用的网页搜索、在收场按需开思考（`story.thinking`）。
- **断连暂缓保护**：平台适配器未启用或 `aiocqhttp` 反向 WebSocket 尚未连上时自动暂缓唤醒并在故事页提示，不空耗唤醒额度。
- **沉淀进同一套记忆**：经历过的事写进记忆表，和聊天记忆一样参与召回、常驻背景、遗忘、夜间巩固与人格蒸馏。

```text
1. 插件 WebUI「配置 → 故事」打开 story.enabled 并保存（基础人设可留空，自动读取该机器人在 AstrBot 配置里的默认人格）
2. 插件 WebUI「故事」页选定机器人，点「导入世界种子」上传 JSON（示例：docs/world_seed.example.json）
3. 点「开启」启动日常巡检，想马上看效果可点「立即演一场」（不消耗唤醒额度）
   （命令备选：种子放进 seed/ 目录后，私聊发 /story import <文件名> → /story on → /story wake）
```

**开启前请了解：**

- **花费**：默认每天回补 10 次唤醒额度，4 轮上限下单次唤醒最多约 15 次模型调用（配角同场时按出场人数增加），可在配置里调低；
- **隐私**：世界设定、故事树、主持人笔记和最近聊天事件的摘要会发给背景模型所用的 provider；`story.chat_digest_items = 0` 可以不发聊天摘要；
- **人格**：故事事件会参与人格蒸馏。建议开启后隔几天看一眼人格有没有被带偏，不合适可以关闭故事并用 `/persona rollback` 回滚。

详细规则、世界种子字段与排障见 [docs/CONFIG.md](docs/CONFIG.md#故事模块)、[docs/DEBUG.md](docs/DEBUG.md#故事模块)。

## 常用命令

管理员 + 仅私聊：

| 命令 | 作用 |
|---|---|
| `/memory` | 当前机器人的记忆状态 |
| `/memory export [seed\|full]` | 导出初始种子或完整备份（`full` 含故事世界与配角） |
| `/memory restore <文件> [force]` | 从 `full` 备份恢复 |
| `/memory import <文件> [force]` | 导入 `persona_seed` |
| `/memory distill / consolidate / decay` | 手动触发整理 |
| `/forget <event_id>` | 删除一条事件 |
| `/persona rollback <version>` | 回滚人格版本 |
| `/qzone <正文>` | 手动发一条说说 |
| `/story [status \| on \| off \| pause \| resume \| wake \| import <文件>]` | 故事模块的状态、开关、手动唤醒与种子导入 |

| 工具 | 作用 |

## WebUI

插件详情页 →「记忆总览」：

- **概览与明细**：按机器人查看人格、事实、事件、常驻背景，支持事件重建、导出与导入；
- **转移**：跨机器人合并或整套替换记忆（替换模式一并迁移故事世界、故事树与配角记忆）；
- **故事**：按机器人开启/暂停/立即演一场，查看唤醒额度、状态卡、活跃配角、断连暂缓提示与她记下的最近场景；二次防剧透确认后可看故事树、设定集、完整转录并在线替换世界种子（开启 `spoiler_heavy` 后可改主持人笔记、看配角记忆）；
- **设置**：按机器人覆盖 TTS、群聊门控问题与固定上下文条数（存于插件数据库）；
- **配置**：按「模型 / 记忆 / 互动 / 故事 / 日志 / 按机器人」卡片分层编辑插件配置，保存立即生效。

改完插件 Python 代码或前端静态文件后需要**重载插件**，只刷新浏览器页面不够；仅在「配置」或「设置」页改配置无需重载。

## 已知限制与安全

1. **人格不是稳定实体**：模型可能忽略或违背记忆；蒸馏和巩固也可能失败。
2. **token 与延迟**：完整上下文、工具调用、故事唤醒和夜间整理都会消耗 token；建议 `max_turns=20`，不需要群历史时关闭 `group_message_history_enable`。
3. **外部 JEV 隐私**：开启 `full_context` 后，人格和历史会发到外部判断服务。
4. **平台差异**：QQ 空间依赖 `aiocqhttp`/`napcat`；主动消息要求对应适配器在线且具备主动发送通道（如 NapCat 通用反向 WS `/ws`）；QQ 官方语音需经过 Tencent SILK。
5. **密钥安全**：API key 只写在 AstrBot 插件配置或 `.env`；日志只记录长度和截断预览，不记录密钥。
6. **不是真实记忆**：不要期待它像人类一样持续学习、永久记住一切或产生真实情感。
